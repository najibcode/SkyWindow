## 🚀 How to Run

### Option 1: Direct Local Browser Open
Simply double-click [`index.html`](file:///Users/najib/skywindow/presentation/index.html) or open it in any modern browser:
```bash
open presentation/index.html
```

### Option 2: Via Local Web Server
When the SkyWindow backend is running:
- **URL:** [http://127.0.0.1:8000/pitch_deck.html](http://127.0.0.1:8000/pitch_deck.html)

## ⌨️ Presentation Keyboard Shortcuts

| Key | Action |
|---|---|
| `→` / `Space` / `PageDown` | Advance to Next Slide |
| `←` / `PageUp` | Return to Previous Slide |
| `Home` / `End` | Jump to First / Last Slide |
| `F` | Toggle Fullscreen Mode |
